## 模型逐项核查

| 项目 | 原始行为 / 证据 | 维护版处理 |
|---|---|---|
| `temporal_fc` / `temporal_weigh` | Conv2d(1,1,(30,1))后ReLU；结果不参与注意力或分类输出，参数无梯度。图2 FFEM却画出时间权重与输入相乘 | 移除死计算/参数；保留原Notebook供核查。没有擅自接入，接入会改变方法和梯度 |
| 均值、标准差 | 计算但未用于`abs_diff`或任何后续输出 | 移除，README不再声称融合四种统计量 |
| 波动特征 | 实际只使用每电极时间最大值减最小值；外层abs对有限实数冗余 | 保留max-min，不新增其他统计量 |
| 平均池化、最大池化 | `abs_diff`形状(B,1,30,1)，两个池化输出同形状；时间维已为1，因此均为恒等操作 | 合并计算并明确双路退化；不宣称提取了互补的池化特征 |
| 双路注意力 | 两路使用同一组`fc1/fc2`，各自Sigmoid后相加 | 精确写成`2*sigmoid(fc2(relu(fc1(r))))`，不是`sigmoid(a+b)`、不是平均，也不是Softmax |
| 权重范围 | 两个相同Sigmoid相加，范围[0,2]；不保证电极权重和为1 | 保留该范围；上限可增强输入，不仅抑制 |
| 电极邻域 | (3,1)卷积沿输入电极顺序执行 | 保留；必须记录电极顺序，不能自动当成头皮拓扑距离 |
| 所谓pointwise | `(sampleChannel,1)`卷积跨全部电极，不是通常意义的1x1 pointwise convolution | 为权重键兼容保留`pointwise`属性名，说明中称空间卷积 |
| 时间卷积 | 16输入、32输出、groups=16，即每输入组2个时间滤波器 | 默认保持；不额外加入未出现的1x1卷积 |
| `N1, d` | 构造参数存在但原内部硬编码16、32 | 现实际生效，默认16、2与原有效尺寸一致 |
| `sampleChannel` | 原AEA固定默认30，未接收主模型电极参数；temporal卷积也硬编码30 | 主模型传入电极数；移除未用的硬编码时间分支 |
| 注意力核大小 | 原`i`可传入，但padding固定1，仅i=3时保证尺寸 | 正奇数核，padding=i//2 |
| BatchNorm | `track_running_stats=False`，测试eval也使用当前批次均值/方差 | 默认改为running=True，构成明确协议变更；`batch`选项显式保留原有效行为 |
| GAP、分类头 | AvgPool覆盖时间长度T-k+1，Linear(32,2)，LogSoftmax | 默认保持；训练使用NLLLoss，不把概率传入CrossEntropy |
| 未使用导入 | optuna、优化器、数据/指标导入存在，但未实现搜索/训练 | Notebook原样留档；维护项目不依赖Optuna |

删除死层会改变从头初始化时的随机数消耗顺序，因此“同一初始种子”不保证与旧Notebook同权重。本项目通过复制旧模型有效state_dict来验证输出和梯度一致。旧checkpoint若存在必须审查其来源和BN模式，不能默默忽略不匹配键。

## 实验流程核查与新增协议

原README提及11人LOSO、早停、余弦退火和20–59批量搜索，但未提供验证集来源或训练脚本。无法判断原实验是否曾使用测试被试调参，也不将这个未知项写成既定缺陷。

新增代码采取以下可审查方案：

- 外层整被试留出；内层整被试验证，所有源训练/验证样本索引可从selection记录重建。参数选择函数只接收源数据，不接收目标信号和标签。
- 每个内层折仅在自己的训练分区拟合标准化和BN；不在训练前全局拟合。目标信号不参与模型训练、标准化或超参数选择。
- 候选只按源内验证指标选择；固定规则从内层最佳轮次确定外层训练轮数，然后重新初始化，用全部源数据训练。没有按测试分数选epoch、batch size或checkpoint。
- 新默认BN使用源训练运行统计。显式batch模式会使用目标当前批统计，虽不读取标签，却具有目标批信息依赖，必须单独报告，不能与严格归纳默认协议混用。
- 固定随机种子和调度设置；固定标签语义与阈值（argmax）。不从测试标签估计类别权重、不按目标分布调阈值。
- 记录每折超参数、训练历史、源/测试索引、模型权重、标准化参数、输入hash、软件版本与完成状态。模型checkpoint保存的是外层源训练最终模型，不冒称由测试评估选出的“最佳模型”。

所有折共用同一个输入数组，但训练/选择函数的实参只含源索引。这一结构由测试进一步验证：改变目标标签与信号后，参数选择记录、标准化统计和最终state_dict逐项保持一致。
